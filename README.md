# 🚌 Bus Tracker — Backend

A bus tracking application backend developed using **Java, Spring Boot, and MySQL**, integrated with a React frontend to support the Bus Tracking System.

## 📌 Project Overview

Bus Tracker is a collaborative full-stack project designed to provide backend services for a bus tracking application.

The backend manages application logic, REST API requests, and database integration, while the React frontend provides the user interface.

## ⚙️ Getting Started

### Prerequisites

- Java JDK compatible with the project
- Maven
- MySQL Server
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Swapnil-7262/bus_tracker.git
```

### 2. Navigate to the project directory

```bash
cd bus_tracker
```

### 3. Configure MySQL

Create a MySQL database and configure the database URL, username, and password in your local Spring Boot configuration.

Example configuration:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/bus_tracker
spring.datasource.username=YOUR_DB_USERNAME
spring.datasource.password=YOUR_DB_PASSWORD
```

Replace the database name and credentials with your actual configuration. Keep real credentials out of GitHub.

### 4. Run the application

```bash
mvn spring-boot:run
```

Alternatively, open the project in IntelliJ IDEA and run the main Spring Boot application class.
